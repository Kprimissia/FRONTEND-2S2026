# 🚀 Frameworks Front-end — FRONTEND-2S2026

Este repositório reúne todas as atividades práticas (`01` a `08`), projetos, anotações, resumos e materiais desenvolvidos durante a disciplina de **Frameworks Front-end** ministrada pelo **Prof. Me. Deivison S. Takatu**.

O objetivo é documentar minha evolução ao longo do semestre, centralizando os conteúdos estudados e servindo como portfólio e material de consulta para revisões e futuros projetos de desenvolvimento web.

## 🎯 Objetivo da Disciplina

A disciplina tem como objetivo desenvolver competências para a criação de aplicações web modernas, utilizando tecnologias e frameworks Front-end amplamente adotados pelo mercado.

Ao longo do semestre são abordados conceitos fundamentais do desenvolvimento Front-end, desde a configuração do ambiente até a construção, organização e publicação de aplicações utilizando boas práticas de engenharia de software.

---

## 📚 Conteúdos Estudados

### Fundamentos & Gestão Ágil
- Desenvolvimento Front-end e Arquitetura Cliente-Servidor
- UX/UI, Prototipação e Responsividade
- Gestão Ágil de Projetos Front-End (Requisitos, User Stories, Backlog, Scrum, Kanban e DoD)
- Versionamento com Git e GitHub e Deploy em Nuvem (Vercel e Render)

### JavaScript & Integração com APIs
- JavaScript (Vanilla JS), Manipulação do DOM e Eventos
- Criação de APIs REST com Node.js e Express.js (`GET`, `POST`, `PUT`, `DELETE`)
- Consumo de APIs com `fetch` (`async/await`) e Documentação com Postman

### Frameworks Front-end & CSS
- Comparativo entre React, Vue.js, Angular e Next.js
- Componentização, Props, Virtual DOM, Listas/Keys e Renderização Condicional
- Hooks (`useState`, `useEffect`), Formulários Controlados e Roteamento (`React Router`)
- CSS Box Model, Flexbox e Frameworks CSS Utility-First (**Tailwind CSS**)
